# @patchwork/dashboard

The operator and developer dashboard for PATCHWORK.

## Responsibilities (Phase 2 & 3)
- Website and patch explorer.
- Visual element selector and target fingerprint inspector.
- Patch editor supporting allowlisted operations (`style.set`, `text.set`, `attribute.set`, `element.hide`, `element.show`).
- Isolated preview frame (`?patchwork_preview=<patchId>`).
- Verification runner triggers and screenshot results viewer.
- Release manager with atomic rollback action and full audit trail timeline.
